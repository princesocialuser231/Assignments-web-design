CSS Positioning Properties

1. Static Positioning

Static is the default positioning method. The element follows the normal flow of the document.

Static Box: I stay in the normal document flow.

2. Sticky Positioning

Scroll the page to observe the sticky element. It sticks near the top of the viewport while its section scrolls.

Sticky Box: I stick below the navigation bar!

Sticky positioning combines normal document flow with position-based movement during scrolling.

3. Relative Positioning

A relatively positioned element moves from its original position while its original space remains reserved.

Relative Box: Shifted 25px right and 10px down.

4. Absolute Positioning

An absolutely positioned element is placed relative to its nearest positioned ancestor.
